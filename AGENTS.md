# Agent notes

Set up the repo with [How to set up the app](docs/runbooks/setup/HOW_TO_SETUP_APP.md). Start the participant UI with [How to run the app](docs/runbooks/HOW_TO_RUN_APP.md).

The runnable app is the Next.js prototype in `ui/`. Next.js is the web framework used in `ui/`. Python at the repo root is for lint and tests only.

`ui/AGENTS.md` is generated during `next dev`. Do not use `ui/AGENTS.md` as project setup.
