# Issue Discussion Platform

University research prototype for short AI-mediated disagreement conversations.

## Apps

- `ui/` — participant Next.js prototype (Phase 1–2)
- Backend / realtime wiring comes later (Phase 3)

## UI quick start

```bash
cd ui
npm install
npm run dev
```

Edit participant wording in `ui/content/` rather than in React files. See [Where to edit participant wording](docs/runbooks/setup/HOW_TO_SETUP_APP.md#where-to-edit-participant-wording).
